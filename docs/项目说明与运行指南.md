# 项目说明与运行指南

## 这个项目是做什么的

这是一个**推文内容处理流水线**，核心目标是：

- 输入多语言推文（中文/英文等）
- 先把非中文翻译成中文
- 再按你定义的“敏感标签”做多标签分类
- 输出每条推文的原文、中文文本和标签结果

主要用于**内容安全筛查/标签化**，当前支持：

- 输入格式：`JSON`、`JSONL`、`CSV`、`Excel(.xlsx)`
- 模型调用：默认 DashScope（Qwen，OpenAI 兼容接口），也兼容其它 OpenAI 兼容服务
- 容错能力：
  - 启动前做 API 连通性检测
  - 单条失败不会中断全任务
  - 支持断点续跑（`--resume`）

输出字段说明：

- `raw`：原始推文
- `text_zh`：中文内容（翻译后或原文）
- `labels`：命中标签（如“可能涉及反动言论”或“无敏感内容”）
- `error`（可选）：单条调用失败时的错误信息

---

## 如何运行

在项目根目录执行：

### 1）安装依赖

```bash
pip install -r requirements.txt
```

### 2）配置文件

```bash
cp .env.example .env
cp config.example.yaml config.yaml
```

- 在 `.env` 中填写 `DASHSCOPE_API_KEY=...`（若使用公网 DashScope）
- 在 `config.yaml` 中配置 `model` / `base_url` / `labels` / `api_timeout` 等

### 3）执行命令

#### 示例数据

```bash
python main.py
```

#### CSV 输入（常用）

```bash
python main.py data/推特用户帖子数据.csv data/result.json --text-column "被回复或转发帖子内容"
```

#### Excel 输入（默认 W 列）

```bash
python main.py data/推特数据.xlsx data/result.json --excel-column W
```

#### 断点续跑

```bash
python main.py data/推特用户帖子数据.csv data/result.json --text-column "被回复或转发帖子内容" --resume
```
